# RUBIK Fashion — versión pública

Derivada del repositorio propio WEB-RESTAURACI-N-PREMIUM-DIN-MICA, con su motor, contrato de proyecto, Studio y biblioteca compartida. La aplicación de moda es fashion.html; Vercel la sirve en la raíz.

- Campaña rubia activa por defecto; archivo original y nueva campaña en Biblioteca.
- Hero con cuatro transiciones y sus vueltas; secciones editoriales de imagen y vídeo con parallax.
- Modelo masculino 03: imagen base generada, disponible en Biblioteca y modelo-03.html. Sus vídeos todavía no están producidos.
- Studio guarda en este navegador. Publicar el código y los recursos en Vercel no convierte esos cambios locales en edición global ni crea autenticación de administradores.

El bundle compilado del hero está versionado en assets/fashion-hero. Para reconstruirlo: npm ci y npm run build dentro de packages/fashion-hero.

No se incluyen las grabaciones de pantalla ni los másteres y capturas de QA locales en esta copia de publicación. Las atribuciones de los recursos originales se conservan en assets/fashion/ATTRIBUTION.txt.
